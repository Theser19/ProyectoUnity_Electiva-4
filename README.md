## Configuración de Firebase

Los archivos de configuración de Firebase no se incluyen en el repositorio. Para compilar el proyecto, descarga `google-services.json` desde la consola de Firebase (Configuración del proyecto → Tus apps → Android) y colócalo en `Game_ProyectoUnity_Electiva-3/Assets/`. El plugin de Firebase genera el resto de archivos al abrir el proyecto en Unity.
